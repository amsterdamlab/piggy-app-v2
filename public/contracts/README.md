# Carpeta de Contratos Base

Aquí se debe colocar el archivo PDF plantilla del contrato marco:
- **Nombre de archivo esperado:** `contrato_base.pdf`
- **Ruta final:** `public/contracts/contrato_base.pdf`

Este archivo es utilizado por el sistema para estampar la firma del comprador, su nombre, cédula y los metadatos de auditoría al momento de adquirir un Piggy.
